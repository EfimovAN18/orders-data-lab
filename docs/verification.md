# Выполненные проверки

Проверка подготовленной версии: 3 октября 2026 года.

## Выполнено локально

- Python 3.12.14, SQLite, Linux.
- 28 тестов pytest: API, валидация, повторные запросы, статусы, историческая цена, ETL, откат невалидного снимка, метрики, нулевые знаменатели, пустые месяцы и генерация отчёта.
- Полный сценарий `python -m orders_lab demo` на новой базе: 600 заказов, 477 оплаченных, 72 отменённых; выручка 5 271 783,00 ₽, средний чек 11 051,96 ₽.
- График отчёта проверен визуально: подписи читаемы, даты и категории отображаются, единицы измерения указаны.
- Установка проекта в editable-режиме с `.[dev,postgres]` и `constraints.txt` выполнена успешно.
- Сборка wheel выполнена успешно; SQL-файлы включены в пакет.
- `ruff check .` и `ruff format --check .` завершились успешно; схема OpenAPI генерируется.

Тестовый клиент Starlette выдал предупреждение об устаревающей интеграции с `httpx`. Оно не привело к ошибкам тестов. Версии проверенного окружения сохранены в `constraints.txt`.

## Подготовлено для последующей проверки

- Docker Compose с PostgreSQL 17 и отдельным процессом регулярного ETL.
- GitHub Actions: Python 3.12/3.13 с SQLite и отдельный job с PostgreSQL.
- Инструкции для Windows PowerShell.

В среде подготовки отсутствовали Docker и сервер PostgreSQL; запуск контейнеров и тестов на PostgreSQL локально не выполнялся. Проверки на Windows также не выполнялись. Workflow будет проверен фактически после публикации репозитория и запуска GitHub Actions.

Это перечисление подтверждённых проверок, а не заявление о готовности к промышленной эксплуатации.
